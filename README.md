# Calculadora de Texto

Herramienta sencilla para analizar texto: cuenta palabras, caracteres, oraciones y párrafos.

## Funcionalidades

- Conteo de caracteres (con y sin espacios)
- Conteo de palabras
- Conteo de oraciones
- Conteo de párrafos
- Detección de la palabra más larga y más corta

## Cómo usarlo

1. Abre `index.html` en tu navegador
2. Escribe o pega texto en el área de entrada
3. Haz clic en **Analizar**
4. Observa los resultados
